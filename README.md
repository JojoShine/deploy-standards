# Deploy Standards

个人项目统一使用的部署规范，采用 MIT 许可证。

完整约定见 [DEPLOYMENT.md](DEPLOYMENT.md)。接入项目时先由用户确认两个独立选择，不写死默认拓扑：

- PostgreSQL：随栈容器部署，或连接用户提供的已有实例。
- 前后端：合并部署，或独立部署（前端镜像/版本化静态文件）。

源码前后端分离不代表必须独立部署。项目只维护和验证用户确认的方案，不必实现所有组合。

规范覆盖对应模式的目录、Docker/Compose、数据库角色与持久化、迁移及初始化、CI/GHCR、前后端发布清单、宿主机 Nginx 和回滚。后端应用、迁移和初始化共用同一后端镜像摘要；独立前端按发布清单关联其产物。

各项目维护自己的部署文件。本仓库仅保存规范文档。

许可：[MIT](LICENSE)。
